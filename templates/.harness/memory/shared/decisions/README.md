# Decisions

Architectural and technical decisions made during project development.

## What to Store Here

- Technology choices (database, framework, library)
- Architecture decisions (patterns, structure)
- Design trade-offs
- Process decisions

## File Format

```yaml
---
type: decision
topic: brief-topic-slug
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

```markdown
# Decision: [Title]

## Context
What situation required this decision?

## Alternatives Considered
- Option A: [description] — pros/cons
- Option B: [description] — pros/cons

## Decision
What was decided and why.

## Consequences
What are the implications of this decision.
```

## Naming Convention

```
001-database-choice.md
002-authentication-approach.md
003-api-versioning-strategy.md
```
