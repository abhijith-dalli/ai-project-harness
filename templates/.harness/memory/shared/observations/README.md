# Observations

Useful discoveries that are not necessarily decisions or lessons.

## What to Store Here

- Code patterns discovered
- Behavior observations
- Performance characteristics
- Integration behaviors
- Tool quirks or limitations

## File Format

```yaml
---
type: observation
topic: brief-topic-slug
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

```markdown
# Observation: [Title]

## What Was Observed
Description of the discovery.

## Context
When/where this was observed.

## Significance
Why this matters for the project.

## Evidence
Code references, logs, or measurements.
```

## Naming Convention

```
001-cache-invalidation-pattern.md
002-api-rate-limit-behavior.md
003-test-flakiness-cause.md
```
