# Project Memory

Stable project facts and conventions. These are always-available context for AI agents.

## What to Store Here

- Technology stack facts
- Coding conventions
- Architecture overview
- Team preferences
- Deployment details
- Environment requirements

## Example Files

```
project/
├── stack.md          Technology stack details
├── conventions.md    Coding conventions
└── architecture.md   High-level architecture
```

## Format

```markdown
# [Topic]

## Facts
- [fact 1]
- [fact 2]

## Conventions
- [convention 1]
- [convention 2]

## Last Updated
YYYY-MM-DD
```
